# VirtualDiapo — Asset Pack v1

Direction artistique : rétro photographique élégant, anthracite / crème / ambre.

## Important
- Les SVG sont des assets vectoriels sources et peuvent être recolorés/convertis par la build Android/JavaFX.
- Les fonds TV sont en 3840×2160 WebP lossless.
- Les carrousels sont des PNG transparents réutilisables : la photo, le nom du carrousel et le nombre de diapos doivent être superposés dynamiquement.
- La signature reste du vrai texte dans les interfaces : « Les souvenirs se partagent ensemble. »
- Aucune police n'est incluse dans ce pack. Utiliser Inter via une source/dépendance officielle ou une police système adaptée.
