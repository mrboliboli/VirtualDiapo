Projet VirtualDiapo

Avant toute modification :
- comprendre la demande ;
- respecter l'architecture existante ;
- ne pas modifier la direction artistique sans validation ;
- compiler et tester après modification.

Pour toute création ou modification graphique :
- déléguer au rôle Visual Designer ;
- utiliser docs/design comme source de vérité.

Après une modification significative :
- faire effectuer une revue indépendante ;
- ne pas considérer une feature terminée tant que
  les problèmes BLOCKER/MAJOR ne sont pas traités.


## Visual design


For any task involving:
- graphical assets,
- visual composition,
- image generation,
- UI visual consistency,
- modification of the approved visual identity,

delegate the visual analysis to the `designer` custom agent.

The designer must use the `virtualdiapo-designer` skill.

Do not allow the implementation agent to improvise a new visual direction.
